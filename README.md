# Peptide Platform Benchmarks

Public benchmark datasets for the Receptor.AI peptide platform.

## Benchmarks

- [`affinity_benchmark/`](affinity_benchmark/) — rank a peptide series by
  predicted affinity. 10 datasets over 8 targets, full and cropped. This release
  holds the procedure and the input structures. It holds no results. See its
  [README](affinity_benchmark/README.md).
